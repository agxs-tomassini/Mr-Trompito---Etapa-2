# Mr. Trompito | Alquiler de Maquinaria y Servicios de Mudanzas

Sitio web desarrollado para un emprendimiento familiar dedicado al alquiler de maquinaria y herramientas para la construcción, además de ofrecer servicios de mudanzas y fletes en Buenos Aires.

El proyecto tiene como objetivo brindar una plataforma moderna, intuitiva y adaptable a distintos dispositivos, donde los usuarios puedan conocer los servicios disponibles, explorar la maquinaria y solicitar presupuestos de manera sencilla.

### 🌐 Demo del proyecto

**[Ver sitio web en GitHub Pages](https://agxs-tomassini.github.io/Mr-Trompito---Etapa-2/)**

## 🛠️ Tecnologías utilizadas

- **HTML5:** estructura semántica del sitio web.
- **CSS3:** personalización de estilos y diseño visual.
- **Bootstrap 5:** sistema de grillas, componentes y diseño responsive.
- **Git y GitHub:** control de versiones y alojamiento del código.
- **GitHub Pages:** publicación del sitio web.

## 🚀 Funcionalidades principales

### Página de inicio
Presentación del emprendimiento, sus servicios principales y una galería de maquinaria y herramientas disponibles.

### Catálogo de maquinaria
Exhibición de los equipos destinados al alquiler, incluyendo hormigoneras, andamios y distintas herramientas de construcción.

### Servicios de mudanzas y fletes
Información sobre los servicios de transporte y traslado ofrecidos por el emprendimiento.

### Cotizador interactivo
Formularios desarrollados para facilitar las solicitudes de presupuestos de alquiler de maquinaria y servicios de transporte.

### Diseño responsive
Interfaz adaptable a computadoras, tablets y dispositivos móviles mediante Bootstrap y estilos personalizados.

### Sección de contacto
Espacio destinado a facilitar la comunicación entre los clientes y el emprendimiento.

## 📱 Diseño y experiencia de usuario

El sitio fue desarrollado priorizando:

- Navegación sencilla e intuitiva.
- Distribución clara de la información.
- Adaptabilidad a diferentes tamaños de pantalla.
- Identidad visual consistente.
- Accesibilidad y estructura semántica.
- Formularios organizados para mejorar la experiencia de usuario.
